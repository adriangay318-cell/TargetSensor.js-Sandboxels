# TargetSensor.js-Sandboxels
This Repository is to add TargetSensors to Sandboxels.

How to add the mod:
+ Click on the .js file name in the repository list.
+ Click the Raw button at the top right of the code box.
+ Copy the URL from your browser's address bar.
+ Paste this URL into the Sandboxels Mod Manager to load the mod directly from GitHub.
